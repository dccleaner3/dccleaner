# 디시클리너 기능 총정리

디시클리너는 **내 디시 글·댓글 삭제**로 시작했지만, 지금은 이런 것도 할 수 있어요.
전부 **무료**고, 앱 아래 탭 **더보기** → **기능**에 모여 있어요.

## 🧹 댓글 자동 정리 {#comment-auto-delete}

**새로 쓴 내 글의 광고 댓글, 달리는 대로 지워요.**

차단할 단어를 정해 두면, 기능을 켠 뒤에 쓴 글에 그 단어가 들어간 댓글이 달릴 때 자동으로 지워요. 디시 앱이나 웹에서 쓴 글도 돼요.

- 일반 단어 + 정규식(고급)
- Android는 백그라운드에서 계속 동작
- Android · PC

👉 [디시 댓글 자동삭제 설정법 보기](./comment-auto-delete.html)

## 💌 방명록 한 번에 보내기 {#guestbook}

**여러 사람의 갤로그 방명록에 같은 글을 한 번에.**

식별코드 목록(또는 목록 링크)과 메시지만 넣으면 한 명씩 차례대로 보내요.

- 갤창랭킹으로 갤러리에서 활동한 사람들의 식별코드를 바로 뽑아요
- 수만 명도 넣을 수 있어요
- 겹치는 식별코드는 한 번만
- Android는 이미 보낸 사람을 자동으로 빼요
- Android · PC

👉 [디시 방명록 한 번에 보내는 법 보기](./guestbook.html)

## 📊 갤창랭킹 {#ranking}

**우리 갤 갤창, 누군지 순위로 보여 드려요.**

갤러리 주소만 넣으면 하루·주·달 단위로 **시간순·글순·댓글순** 순위를 만들어요. 이미지로 저장하거나 텍스트로 복사해서 바로 올릴 수 있어요.

- 정식·마이너·미니 갤러리 모두 돼요
- 카드형·표형 이미지, 하루 타임라인
- 집계된 사람들을 방명록 받는 사람으로 바로 넣기
- Android · PC

👉 [디시 갤창랭킹 만드는 법 보기](./gallery-ranking.html)

## 🔎 반고닉 글 찾기 {#user-posts}

**이 사람이 우리 갤에 쓴 글, 한 번에 모아 봐요.**

갤러리와 **식별코드**(또는 **유동 IP** 앞 두 자리와 닉네임)를 넣으면 그 사람이 쓴 글만 골라 최신순으로 보여 줘요.

- 고닉·반고닉·유동 모두
- 갤로그 주소를 붙여 넣어도 돼요
- Android · PC

👉 [디시 반고닉 글 검색하는 법 보기](./user-posts.html)
