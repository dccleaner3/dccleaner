# 디시클리너 (디시 클리너)

**내 디시인사이드 게시글과 댓글, 원하는 것만 골라 한 번에 지워요.** 글·댓글 일괄삭제부터 갤로그 정리까지 한 앱으로 해요.
Android, Windows, macOS에서 쓰는 무료 오픈소스 프로그램이에요.

[디시클리너 최신 버전 다운로드](https://github.com/dccleaner3/dccleaner/releases/latest){: .cta}

| 지원 운영체제 | 제공 형태 |
| --- | --- |
| Android | APK |
| Windows | 데스크톱 앱 |
| macOS | 데스크톱 앱 |
| iOS | 지원하지 않음 |

> 본인 계정의 게시글과 댓글을 관리하는 용도로만 사용하세요. 디시클리너는 디시인사이드의 공식 프로그램이 아닙니다.

## 주요 기능

👉 **[기능 총정리 한 번에 보기](./features.html)**

### 게시글·댓글 정리
- **글·댓글 한 번에**: 게시글과 댓글을 각각 다른 조건으로 골라 한 번에 이어서 지워요. ([도움말](./help.html#both))
- **갤러리별 삭제**: 활동한 갤러리 중 원하는 곳의 게시글·댓글만 골라 지워요.
- **남길 글 지정**: 추천 수나 댓글 수가 일정 이상인 글은 남겨요.
- **댓글 필터**: 내 글에 단 댓글, 디시콘 댓글, 정한 단어나 패턴이 들어간 댓글만 고를 수 있어요.
- **기간 조건**: 정한 일수보다 오래된 글과 댓글만 지워요.
- **이어하기**: 앱 종료, 네트워크 오류, 캡챠로 멈춘 작업을 그대로 이어서 해요.
- **백그라운드 실행**: Android에서는 화면을 꺼도 계속 지워요.
- **캡챠**: 직접 풀거나 2Captcha로 자동 해결해요. 삭제 중에 키를 넣어도 바로 적용돼요. ([도움말](./help.html#captcha-auto-running))

### 초고속 삭제 (유료)
서버가 대신 지워요. **캡챠 없이, 앱을 꺼도 계속, 더 빠르게.**
필요한 만큼만 충전해 쓰고, 남은 개수는 다음에도 쓸 수 있어요. ([도움말](./help.html#ultra))
직접 삭제 중에 충전하면 바로 초고속 삭제로 바꿔 시작할 수 있어요. ([도움말](./help.html#ultra-switch))

### 댓글 자동 정리
내가 새로 쓴 글에 정한 단어가 들어간 댓글이 달리면 자동으로 지워요. 디시 앱·웹에서 쓴 글도 돼요. ([디시 댓글 자동삭제 설정법](./comment-auto-delete.html))

### 방명록 한 번에 보내기
식별코드 목록에 같은 방명록을 한 번에 보내요. 갤창랭킹에서 뽑은 식별코드를 받는 사람으로 바로 넣을 수 있고, Android에서는 이미 보낸 사람이 자동으로 빠져요. ([디시 방명록 한 번에 보내는 법](./guestbook.html))

### 갤창랭킹
갤러리에서 누가 제일 활발했는지 하루·주·달 순위를 만들어 이미지나 텍스트로 공유해요. ([디시 갤창랭킹 만드는 법](./gallery-ranking.html))

### 반고닉 글 찾기
식별코드나 유동 IP로 한 사람이 갤러리에 쓴 글만 골라 모아 봐요. ([디시 반고닉 글 검색하는 법](./user-posts.html))

## 자주 묻는 질문

### 무료인가요?
네, 프로그램은 무료 오픈소스예요. 2Captcha 자동 해결을 쓰면 해당 서비스 비용은 별도로 들어요. 초고속 삭제는 선택형 유료 기능이에요.

### iPhone에서도 쓸 수 있나요?
앱은 Android, Windows, macOS만 지원해요. iPhone에서는 앱 없이 [초고속 삭제(유료)](./help.html#ultra-iphone)로 서버가 대신 지워 드려요.

### 전부 지워야 하나요?
아니요. 게시글·댓글, 갤러리, 기간, 추천 수·댓글 수 조건으로 원하는 것만 지울 수 있어요.

### 중간에 앱을 끄면 처음부터 다시 해야 하나요?
아니요. 작업과 삭제 대기열이 저장돼서 이어서 할 수 있어요. 초고속 삭제는 앱을 꺼도 서버에서 계속 진행돼요.

### 로그인 정보는 안전한가요?
아이디·비밀번호는 로그인할 때 디시인사이드로만 보내고, 로그인 정보 저장을 켜면 기기 보안 저장소에만 저장해요. 초고속 삭제는 별도 동의 후 AES-256으로 암호화해 보내고, 작업이 끝나면 바로 폐기해요. [소스 코드](https://github.com/dccleaner3/dccleaner)에서 직접 확인할 수 있어요.
