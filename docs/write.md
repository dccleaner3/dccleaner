## 여러 갤러리에 한 번에 쓰기 {#write}

> Android 앱에서만 쓸 수 있어요.

### 1. 갤러리 등록하기

1. **작성할 갤러리**를 눌러요.
2. 갤러리 주소를 넣어요. **모바일 주소만 돼요.**
   - `https://m.dcinside.com/board/갤러리ID`
   - `https://m.dcinside.com/write/갤러리ID`
3. 등록한 갤러리는 자동으로 선택돼요.

> **💡 팁** PC 주소(`gall.dcinside.com`)는 등록되지 않아요. 휴대폰 브라우저에서 모바일 디시로 갤러리를 열고 주소를 복사해 주세요.

- 체크로 이번에 쓸 갤러리를 골라요.
- 지우려면 휴지통으로 표시한 뒤 **삭제 (N)**을 눌러요.
- 같은 갤러리는 두 번 등록할 수 없어요.

### 2. 글쓰기 시작하기

아래 버튼이 상황에 맞게 바뀌어요.

| 버튼 | 뜻 |
| --- | --- |
| 갤러리 추가하기 | 등록한 갤러리가 없어요 |
| 갤러리 고르기 | 체크한 갤러리가 없어요 |
| N개 갤러리에 글쓰기 | 바로 시작할 수 있어요 |

### 3. 이렇게 올라가요

1. **첫 번째 갤러리**의 디시 모바일 글쓰기 화면이 열려요. 평소처럼 직접 작성해요.
2. 첫 글을 등록하면, 같은 제목·본문·이미지가 **나머지 갤러리에 자동으로** 올라가요. (최대 10곳씩 동시에)
3. **추가 갤러리 X / Y 완료**로 진행 상황을 볼 수 있어요.

**뒤로 가기**를 누르면 글쓰기 화면 안에서 이전 페이지로 가요. 더 돌아갈 곳이 없으면 글쓰기를 끝내요.

### 이미지 제한

여러 갤러리에 쓸 때는 이미지에 제한이 있어요.

- 최대 **20개**
- 음악 이미지 포함 합계 **50MB**

이미지가 클수록 동시에 올리는 갤러리 수가 줄어서 느려질 수 있어요.

### 오류가 났다면

**글쓰기 오류** 창이 뜨면, 다시 시도하기 전에 **각 갤러리에 글이 이미 올라갔는지 먼저 확인해 주세요.** 일부는 이미 등록됐을 수 있어서, 바로 다시 쓰면 같은 글이 두 번 올라갈 수 있어요.

3분 동안 등록 응답이 없으면 자동으로 중단돼요.

## 음악 첨부 {#music}

> Android 앱에서만 쓸 수 있어요.

지금 듣는 곡을 **840×400 이미지 카드**로 만들어 글에 붙여요. 카드에는 이런 정보가 들어가요.

- 현재 재생 중 · 플랫폼
- 제목, 아티스트, 앨범 아트
- 진행 바, 재생 시간

곡은 **글쓰기 버튼을 누르는 순간** 다시 확인해요. 그 사이 곡이 바뀌어도 최신 곡이 들어가요.

### 1. 음악 연동 앱 설치하기

별도 앱 **DCCleaner 음악 연동**이 필요해요.

- 앱의 **설치** 버튼을 누르거나
- [GitHub Releases](https://github.com/dccleaner3/dccleaner/releases/latest)에서 받아요.

> **안심하세요.** 연동 앱은 **곡 정보만** 본앱에 전달하고, 디시 로그인 정보나 글 내용에는 접근하지 않아요.

### 2. 연결하기

1. 연동 앱을 열어요.
2. **권한 설정하기**를 눌러요.
3. Android 알림 접근에서 **DCCleaner 재생 곡 연동**을 허용해요.

### 3. 상태 확인하기

| 표시 | 할 일 |
| --- | --- |
| 음악 연동 앱 설치 필요 | 연동 앱을 설치해요 |
| 음악 연동 앱 업데이트 필요 | 최신 연동 앱을 설치해요 |
| 연동 앱에서 권한 설정 필요 | 알림 접근을 허용해요 |
| 음악 연동 앱 연결됨 | 준비 끝이에요 |

### 4. 음악 앱 켜기

지원 앱: **YouTube Music, 멜론, Spotify, Apple Music, SoundCloud**

> **⚠️ 꼭 켜 주세요** 처음엔 모두 꺼져 있어요. 쓰는 앱을 하나 이상 켜야 곡을 읽어요.

### 꾸미기

- **배경색**: 프리셋 6개 중에서 고르거나 색상 코드(예: `#0D1117`)를 직접 넣을 수도 있어요.
- **대체 이미지 URL**: 재생 중인 곡이 없을 때 대신 붙일 이미지예요. `http`/`https` 주소, 12MB 이하만 돼요. 큰 이미지는 자동으로 줄여요.

미리보기는 그 시점의 이미지예요. 실제로 붙는 이미지는 글쓰기를 시작할 때 다시 확인해요.

## 댓글 자동 정리 {#comment-cleaner}

> Android와 PC 모두 쓸 수 있어요.

내 글에 차단 규칙에 걸리는 댓글이 달리면 자동으로 지워요.

### 어떤 글을 감시하나요?

**기능을 켠 뒤 새로 쓴 글만** 감시해요. 켜기 전에 있던 글은 처리하지 않아요.

예전 글의 댓글은 앱의 **클리너** 탭에서 댓글 삭제로 정리해 주세요.

- **확인 간격**: 새 글을 찾는 간격이에요. 기본 60초, 최소 5초.
- **감시 시간**: 새 글을 찾은 뒤 댓글을 지켜보는 시간이에요. 기본 10분, 최소 1분.

두 설정은 [디시콘 자동 답글](#dccon-reply)과 함께 써요.

### 차단 규칙 쓰기

한 줄에 하나씩 적어요.

- **일반 단어**: 댓글에 포함되면 지워요. 대소문자는 구분하지 않아요.
- **정규식**(여러 단어나 숫자 패턴을 한 줄로 거르는 고급 규칙): `정규식:`으로 시작해요.

```
광고
홍보
정규식:(광고|홍보)\d+
```

정규식 문법이 틀리면 기능이 켜지지 않아요.

### 설정을 바꾸려면

실행 중에는 설정을 바꿀 수 없어요. **끄고 → 바꾸고 → 다시 켜요.**

### 어디서 동작하나요?

- **Android**: 백그라운드에서 동작해요. 알림에 **내 글 댓글 감시 중**이 떠요.
- **PC**: 앱이 켜져 있고 로그인한 동안에만 동작해요. 계속 돌리고 싶다면 Android를 써 주세요.

다시 로그인하면 켜 두었던 기능이 자동으로 다시 시작돼요.

## 디시콘 자동 답글 {#dccon-reply}

> Android와 PC 모두 쓸 수 있어요.

내 글에 새 댓글이 달리면 AI가 대화 흐름(글 제목, 앞선 댓글 최대 3개)을 보고 **가장 어울리는 내 디시콘으로** 답글을 달아요. 어울리는 게 없으면 답하지 않아요.

대왕콘이 풀린 계정이면 대왕콘으로, 아니면 일반 디시콘으로 보내요.

### 답하지 않는 댓글

- 내 댓글
- 답글에 단 답글 — 글에 바로 달린 댓글에만 답해요 (대화가 끝없이 이어지지 않게)
- 디시콘만 단 댓글 (움짤 디시콘 포함)
- 차단 규칙에 걸린 댓글 — [댓글 자동 정리](#comment-cleaner)가 먼저 지워요.

한 댓글에는 **한 번만** 답해요. 실패해도 다시 시도하지 않아요. 같은 댓글로 요금이 반복해서 나가지 않게 하려는 거예요.

### 1. OpenAI API 키 넣기

- [platform.openai.com](https://platform.openai.com)에서 API 키를 발급받아 입력해요.
- 요금은 **내 OpenAI 계정**에 청구돼요.
- 키는 이 기기에만 암호화해서 저장해요. (Android 암호화 저장소, macOS 키체인, Windows 자격 증명 관리자)

### 2. 내 디시콘 다운로드하기

1. 설정 화면을 열면 보유한 디시콘을 불러와요.
2. 쓸 묶음의 **다운로드**를 눌러요.
3. 예상 비용을 확인하고 **분석 시작**을 눌러요.
4. AI가 디시콘마다 뜻을 한 번만 정리해요. 움직이는 디시콘은 장면 4개를 보고 판단해요.
5. 끝나면 묶음 전체가 자동으로 선택돼요.

### 3. 쓸 디시콘 고르기

- 묶음을 펼쳐서 **탭**하면 선택/해제돼요.
- **전체 선택**으로 한 번에 고를 수 있어요.
- **길게 누르면** AI가 정리한 설명을 볼 수 있어요.

> **💡 150개 이하를 권장해요.** 많이 고를수록 답글마다 비용이 늘고, 고르는 정확도는 떨어져요.

### 비용

OpenAI 요금은 두 번 나가요.

- **다운로드할 때** (묶음당 한 번)
- **답글을 달 때마다**

앱이 예상 비용을 원화로 보여줘요. 1달러=1,400원으로 계산한 값이라 실제와 다를 수 있어요. 다운로드가 끝나면 실제로 쓴 금액을 보여줘요.

## 자주 묻는 질문 {#faq}

### "API 키가 올바르지 않아요"가 떠요

키가 잘못 복사됐거나 삭제된 키예요. [platform.openai.com](https://platform.openai.com)에서 키를 다시 확인하거나 새로 발급해 입력해 주세요.

### "OpenAI 크레딧이 부족해요. 결제 정보를 확인해 주세요"가 떠요

OpenAI 계정에 남은 크레딧이 없어요. OpenAI 결제 페이지에서 결제 수단을 등록하거나 크레딧을 충전해 주세요.

### "보유한 디시콘이 없어요"가 떠요

계정에 받은 디시콘이 없어요. 디시콘샵에서 디시콘을 받은 뒤 설정 화면에서 새로고침해 주세요.

### "디시콘 목록을 불러오지 못했어요"가 떠요

로그인이 풀렸을 수 있어요. 로그인 상태를 확인하고 다시 열어 주세요.

### "확인 간격은 5초 이상이어야 합니다"가 떠요

확인 간격은 5초보다 짧게 할 수 없어요. 5 이상으로 입력해 주세요.

로그인·캡챠·초고속 삭제는 [도움말](./help.html), 다운로드는 [소개 페이지](./)를 봐 주세요.
