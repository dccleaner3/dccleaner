## ✨ 주요 기능

- 🗑️ **게시글·댓글 정리**  
  내 갤로그에 작성한 게시글과 댓글을 종류별로 나누어 삭제할 수 있습니다.

- 📂 **갤러리별 선택 삭제**  
  활동한 갤러리를 검색하고 여러 개를 선택해 원하는 갤러리의 기록만 정리할 수 있습니다.

- 🛡️ **게시글 보존 조건**  
  일정 추천 수 또는 댓글 수 이상인 글은 남겨둘 수 있습니다. 두 조건을 함께 사용하면 둘 중 하나만 충족해도 보존됩니다.

- 🎯 **댓글 상세 필터**  
  내가 작성한 글에 단 댓글, 디시콘 댓글, 정규식과 일치하는 댓글만 골라 삭제할 수 있습니다.

- 📅 **오래된 항목만 삭제**  
  지정한 일수 이상 지난 게시글·댓글만 삭제하도록 기간 조건을 추가할 수 있습니다.

- 📊 **실시간 진행 상황**  
  현재 처리 중인 갤러리, 진행률, 예상 남은 시간, 삭제 로그와 다음 캡챠 예상 시간을 보여줍니다.

- ⏸️ **중단 작업 저장 및 이어하기**  
  사용자가 멈췄거나 네트워크 오류·앱 종료·캡챠로 중단된 작업의 진행 상태와 삭제 큐를 저장하고 이어서 처리할 수 있습니다.

- 🤖 **수동·자동 캡챠 대응**  
  갤로그에서 캡챠를 직접 해결한 뒤 이어가거나, 2Captcha API 키를 등록해 자동으로 처리할 수 있습니다.

- 🔔 **백그라운드 실행 및 알림**  
  화면을 끄거나 다른 앱을 사용하는 동안에도 삭제를 계속하며, 진행 상황과 캡챠·작업 중단 여부를 알림으로 안내합니다.
